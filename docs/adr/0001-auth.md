# 0001. Auth med JWT i httpOnly-cookie og argon2

Dato: 14. november 2026. Status: besluttet.

## Kontekst

Appen skal have login for en lille familie, senere måske flere brugere. API og web ligger på samme domæne bag Caddy (`/api` og `/`). Der er ingen e-mail-udbyder endnu (hul 6).

## Beslutning

- Adgangskoder hashes med argon2id (`@node-rs/argon2`, færdigbyggede binærer, intet build-værktøj i Docker)
- Login giver en signeret JWT i en cookie: `httpOnly`, `Secure` i produktion, `SameSite=Lax`, `Path=/api`
- JWT indeholder kun bruger-id. Gruppe-adgang tjekkes i databasen ved hvert kald
- Hemmeligheden til JWT ligger i `.env` som `JWT_SECRET`
- Nulstilling af adgangskode venter, til der er valgt en e-mail-udbyder

## Hvorfor

- httpOnly-cookie kan ikke læses af JavaScript, så et XSS-hul kan ikke stjæle tokenet. localStorage kan
- Samme domæne betyder ingen CORS og ingen tredjeparts-cookies
- JWT kræver ingen session-tabel. Ulempen er, at et token ikke kan trækkes tilbage før det udløber, så levetiden holdes kort (7 dage)

## Fravalgt

- Sessions i databasen: mere kode nu. Kan tilføjes, hvis vi får brug for at logge enheder ud
- bcrypt: ældre og svagere end argon2id
- Auth-tjenester (Auth0, Clerk): ekstern afhængighed og persondata hos tredjepart
